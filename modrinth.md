Ручные фантомы для Minecraft 1.21.1. Приручение, седло, посадка, поводок и освобождение. Ставится один загрузчик, не оба сразу.

## NeoForge

Обязательно: `tamedphantoms-neoforge-1.21.1-1.0.0.jar`, Kotlin for Forge 5.8.0 (`kotlinforforge-neoforge`). Необязательно: Patchouli `1.21.1-93-neoforge`, только для книги.

## Fabric

Обязательно: `tamedphantoms-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20`. Строка «нужен fabric 0.100.3» означает jar Fabric API, не Fabric Loader. Для экрана настроек нужен Cloth Config `15.0.140`. Необязательно: Mod Menu 11.0.4 (ему нужен Text Placeholder API) и Patchouli `1.21.1-93-fabric`.

---

Tamed phantoms for Minecraft 1.21.1: tame them, saddle them, sit them, leash them, and release them. Install one loader, not both.

## NeoForge

Required: `tamedphantoms-neoforge-1.21.1-1.0.0.jar` and Kotlin for Forge 5.8.0 (`kotlinforforge-neoforge`). Optional: Patchouli `1.21.1-93-neoforge`, only for the guidebook.

## Fabric

Required: `tamedphantoms-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, and Fabric Language Kotlin `1.13.2+kotlin.2.1.20`. A line that says "requires fabric 0.100.3" means the Fabric API jar, not Fabric Loader. Cloth Config `15.0.140` is required for the config screen. Optional: Mod Menu 11.0.4 (it needs Text Placeholder API) and Patchouli `1.21.1-93-fabric`.
