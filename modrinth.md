Tamed phantoms for Minecraft 1.21.1: tame them, saddle them, sit them, leash them, and release them. Install one loader, not both.

## NeoForge

Required: `tamedphantoms-neoforge-1.21.1-1.0.7.jar` and Kotlin for Forge 5.8.0 (`kotlinforforge-neoforge`). Optional: Patchouli `1.21.1-93-neoforge`, only for the guidebook.

## Fabric

Required: `tamedphantoms-fabric-1.21.1-1.0.7.jar`, Fabric API `0.116.17+1.21.1`, and Fabric Language Kotlin `1.13.2+kotlin.2.1.20`. A line that says "requires fabric 0.100.3" means the Fabric API jar, not Fabric Loader. Cloth Config `15.0.140` is required for the config screen. Optional: Mod Menu 11.0.4 (it needs Text Placeholder API) and Patchouli `1.21.1-93-fabric`.

## Minecraft 26.3

The `+26.3` versions need Kotlin for Forge 6.4.0 on NeoForge, or Fabric API, Fabric Language Kotlin, and Cloth Config on Fabric. Patchouli has no 26.3 build, so the guidebook there uses Modonomicon `26.3-2.20.0`, which is optional.

## Addons

[Tamed Phantoms Colors](https://modrinth.com/project/tamed-phantoms-colors) dyes tamed phantoms and their saddles and makes them glow.
