# Tamed Phantoms

**[English](README.md)** · **[Русский](README.ru.md)**

Мод для **Minecraft 1.21.1** (NeoForge): приручение фантомов, полёт на седле, посадка, поводок и освобождение. Написан на Kotlin через [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge).

Интерфейс и внутриигровая книга доступны на русском и английском.

## Загрузки

Готовые jar лежат в [GitHub Releases](https://github.com/Nergan/tamedphantoms-mod/releases/latest). Пуш в `main` обновляет файлы текущего релиза.

Скачайте эти файлы и положите в папку `mods`:

| Файл                               | Обязателен | Что это                                                                  |
| ---------------------------------- | ---------- | ------------------------------------------------------------------------ |
| `tamedphantoms-1.0.0.jar`          | Да         | этот мод                                                                 |
| `kotlinforforge-5.8.0-all.jar`     | Да         | [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge)            |
| `Patchouli-1.21.1-93-NEOFORGE.jar` | Нет        | [Patchouli](https://modrinth.com/mod/patchouli), только если нужна книга |

Workflow релиза собирает мод и забирает два чужих jar с Modrinth. SHA-256 у каждого файла GitHub считает сам и показывает рядом с ним на странице релиза. Файл `*-sources.jar` в `mods` класть не нужно.

## Возможности

- **Приручение.** Правая кнопка мыши по дикому фантому предметом приручения (по умолчанию печенье). Фантом становится крупнее и темнее, глаза загораются зелёным. Пока предмет в руке, дикие фантомы подлетают сами и не нападают.
- **Глаза.** У диких фантомов — кроваво-красные. У прирученных — ярко-зелёные. У освобождённых — ярко-жёлтые. Во время самозащиты глаза снова становятся красными.
- **Следование.** Прирученный фантом держится рядом с хозяином, как обычный питомец.
- **Сидеть.** Правая кнопка мыши (если есть седло — сначала присядьте). Фантом переворачивается, падает и остаётся на месте. Урона от падения нет. Сидя на нём, посадить нельзя; на сидящего сесть нельзя.
- **Седло и полёт.** Хозяин надевает седло и садится верхом. Движение — обычные клавиши ходьбы, прыжок поднимает вверх, левый Control опускает вниз. Клавиши можно сменить в настройках. В полёте даётся ночное зрение. Второй игрок может сесть сзади. Седло снимается ножницами.
- **Поводок.** Прирученного фантома можно взять на поводок и отпустить пустой рукой.
- **Лечение.** Хозяин кормит любой едой.
- **Самозащита.** Если фантома ударили, около десяти секунд он атакует обидчика — в том числе хозяина. Длительность настраивается. С каждой атаки он восстанавливает себе столько здоровья, сколько нанёс урона. Пока он защищается, он может крикнуть, если крик уже готов.
- **Крик.** Хозяин в полёте нажимает R (клавиша в настройках, раздел Tamed Phantoms). Фантом издаёт более громкий и низкий ambient. На секунду глаза краснеют, тело светится, мобы в радиусе разбегаются и слепнут. Слепота не берёт игроков, которые сидят на этом фантоме; хозяин на земле слепнет, если фантом кричит в самозащите. Перезарядка 4 секунды; если крик не готов, красная надпись над хотбаром говорит, сколько секунд осталось. Первое использование даёт достижение «Крылатая тварь». Радиус и перезарядка — серверные настройки. Клиентский ползунок громкости этот крик не приглушает. В полнолуние освобождённый фантом может крикнуть сам, даже если ни на кого не нападает: глаза остаются жёлтыми, свечение всё равно появляется, мобы разбегаются, слепоты нет, а луна на секунду становится болезненно-жёлтой. Слышат все, у кого загружен чанк с фантомом.
- **Фигуры.** В полёте вперёд набор, снижение и повороты продолжают наклонять фантома, так что выходит мёртвая петля или бочка. Камера повторяет этот наклон. В зависании и при полёте назад — нет. Полная петля даёт секретное достижение «Мёртвая петля!»: этот фантом навсегда светится и не умирает.
- **Поводок.** Прирученного можно взять на поводок. Освобождённый неспешно уходит в сторону и срывается.
- **Характеристики.** У прирученного и освобождённого: 40 здоровья, 12 урона, полёт вдвое быстрее обычного фантома. Не горит на солнце и не тонет.
- **Отпугивание.** Прирученный фантом отталкивает диких в радиусе (по умолчанию 64 блока).
- **Освобождение.** Правая кнопка мыши предметом освобождения (по умолчанию ядовитый картофель). Связь пропадает, седло падает, глаза становятся жёлтыми. Такого фантома можно приручить снова.
- **Достижения.** «Крылатый питомец» за приручение, «Больше не в ответе» за освобождение, «Крылатая тварь» за первый крик хозяина и секретное «Мёртвая петля!» за полную петлю.
- **Книга (необязательно).** Если установлен [Patchouli](https://modrinth.com/mod/patchouli), при первом заходе в мир выдаётся «Руководство по приручению фантома». Крафт: обычная книга и мембрана фантома. Без Patchouli мод работает как обычно.

## Установка

1. Установите NeoForge 1.21.1.
2. Скачайте jar из [последнего Release](https://github.com/Nergan/tamedphantoms-mod/releases/latest).
3. Положите в `mods` файлы `tamedphantoms-1.0.0.jar` и `kotlinforforge-5.8.0-all.jar`.
4. По желанию добавьте оттуда же `Patchouli-1.21.1-93-NEOFORGE.jar`.

Мод нужен и на клиенте, и на сервере. Kotlin for Forge и Patchouli можно взять и с [Modrinth](https://modrinth.com/mod/kotlin-for-forge), не из GitHub Release.

## Управление полётом

Настройки → Управление → Tamed Phantoms / Ручные фантомы.

| Действие                 | По умолчанию     |
| ------------------------ | ---------------- |
| Вперёд, назад, в стороны | клавиши движения |
| Взлёт                    | Пробел           |
| Снижение                 | левый Control    |
| Крик                     | R                |

Снижение специально не на Shift: во время езды верхом эта клавиша спешивает.

Управляет только хозяин на переднем месте.

## Настройки

В игре: Mods → Tamed Phantoms → Config.

Файл мира: `saves/<мир>/serverconfig/tamedphantoms-server.toml`.

На выделенном сервере: `world/serverconfig/tamedphantoms-server.toml`. Конфиг типа `SERVER`: значения задаёт сервер и рассылает игрокам.

| Параметр            | По умолчанию                 | Смысл                                          |
| ------------------- | ---------------------------- | ---------------------------------------------- |
| `tame_item`         | `minecraft:cookie`           | предмет приручения                             |
| `release_item`      | `minecraft:poisonous_potato` | предмет освобождения                           |
| `tame_chance`       | `1.0`                        | шанс приручения за одну попытку                |
| `repel_radius`      | `64.0`                       | радиус отпугивания диких фантомов              |
| `defend_time_ticks`       | `200`                        | длительность самозащиты (20 тиков = 1 секунда) |
| `scream_radius`           | `32.0`                       | радиус крика в блоках: мобы разбегаются        |
| `scream_cooldown_seconds` | `4`                          | перезарядка крика в секундах                   |
| `acrobatics_step`         | `0.3`                        | градусы за тик у бочки и мёртвой петли         |
| `insomnia_days`           | `1`                          | суток без сна, после которых могут появиться фантомы |
| `phantom_group_multiplier`| `2.0`                        | во сколько раз группа фантомов больше ванильной |

Клиентский конфиг: `config/tamedphantoms-client.toml` (или Mods → Config в одиночной игре).

| Параметр             | По умолчанию | Смысл                                              |
| -------------------- | ------------ | -------------------------------------------------- |
| `tamed_sound_volume` | `0.5`        | громкость приручённого фантома на этом клиенте     |

Неверный идентификатор предмета заменяется значением по умолчанию, в лог пишется предупреждение.
